💬 文字对话

GET /asrText

文字经大模型对话后返回回复文本（默认「你好」）。

请求参数

参数类型必填默认说明
textstring否你好要发送给大模型的文本
curl 示例
curl "http://localhost:8999/asrText?text=今天天气怎么样"
fetch 示例
const res = await fetch("/asrText?text=今天天气怎么样");
const reply = await res.text();
console.log(reply); // 大模型回复文本

响应：纯文本，如 今天天气很好，适合出门散步。

🎤 语音识别对话

POST /asr

上传原始音频（mp3），经本地 Whisper 识别后由大模型回复文本。

请求参数

参数位置说明
Content-TypeHeaderaudio/mp3
bodyBody原始 mp3 二进制数据（≤100MB）
curl 示例
curl -X POST http://localhost:8999/asr \
  -H "Content-Type: audio/mp3" \
  --data-binary @speech.mp3
fetch 示例（audioBlob 为浏览器录制的 mp3 音频）
const res = await fetch("/asr", {
  method: "POST",
  headers: { "Content-Type": "audio/mp3" },
  body: audioBlob,
});
const reply = await res.text();
console.log(reply); // 大模型回复文本

响应：纯文本，如 我在呢，有什么可以帮你的？

🔊 文字合成语音（暂不启用）

POST /tts

将文本合成为 mp3 语音。

请求参数（Body JSON）

参数类型必填默认说明
textstring是—要合成的文本
voicestring否malele_3F5-TTS 音色 id（见 /voices）
speednumber否1.0语速
seednumber否—固定合成结果（相同输入 + 种子 = 相同结果）
removeSilenceboolean否true是否去除静音
curl 示例
curl -X POST http://localhost:8999/tts \
  -H "Content-Type: application/json" \
  -d '{"text":"你好世界","voice":"malele_3","speed":1.0}' \
  --output out.mp3
fetch 示例
const res = await fetch("/tts", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ text: "你好世界", voice: "malele_3", speed: 1.0 }),
});
const blob = await res.blob();
const url = URL.createObjectURL(blob);
new Audio(url).play(); // 播放合成语音

响应：audio/mp3 二进制音频

😊 语气（情感）语音合成

POST /emotion-tts

支持三种情感控制方式（由 emotionMode 选择，互斥）：
① emotionMode=1 参考音频情感（emoAudioPrompt 为音色 id 或路径）；
② emotionMode=2 8 维情感向量（emoVector）；
③ emotionMode=3（默认）文本情感，由大模型自动推断（emoText 为情感描述）。

请求参数（Body JSON）

参数类型必填默认说明
textstring是—要合成的文本
voicestring否malele_3音色 id
speednumber否1.0语速
seednumber否—固定结果
removeSilenceboolean否true是否去静音
formatstring否mp3音频格式：wav/mp3/ogg/flac
bitratenumber否64仅 mp3 有效，范围 32~128 kbps
emotionModenumber否3情感控制方式：1/2/3
emoAudioPromptstring否—方式 1：音色 id 或参考音频路径
emoAlphanumber否0.65情感强度
emoVectornumber[]否—方式 2：8 维情感向量
emoTextstring否—方式 3：情感描述文本，如「开心地说」
8 维情感向量顺序：[happy, angry, sad, afraid, disgusted, melancholic, surprised, calm]
curl 示例（方式 3 文本情感）
curl -X POST http://localhost:8999/emotion-tts \
  -H "Content-Type: application/json" \
  -d '{"text":"今天天气真好，我们一起去公园散步吧。","emotionMode":3,"emoText":"开心地说"}' \
  --output out.mp3
curl 示例（方式 2 情感向量）
curl -X POST http://localhost:8999/emotion-tts \
  -H "Content-Type: application/json" \
  -d '{"text":"今天天气真好。","emotionMode":2,"emoVector":[0,0,0,0,0,0,0,1],"emoAlpha":0.65}' \
  --output out.mp3
fetch 示例
const res = await fetch("/emotion-tts", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    text: "今天天气真好，我们一起去公园散步吧。",
    emotionMode: 3,
    emoText: "开心地说",
  }),
});
const blob = await res.blob();
new Audio(URL.createObjectURL(blob)).play();

响应：对应 format 的二进制音频

📖 小说语音合成

POST /novelToTts

小说完整链路：小说文本 → LLM 角色/情感识别 → 分段情感 TTS → FFmpeg 合并，返回最终音频。

请求参数（Body JSON）

参数类型必填默认说明
textstring是—小说文本（单次 ≤6000 字）
rolesstring[]否—角色名数组，辅助识别
voicestring否malele_3音色 id
speednumber否1.0语速
formatstring否mp3音频格式
bitratenumber否64仅 mp3，32~128 kbps
curl 示例
curl -X POST http://localhost:8999/novelToTts \
  -H "Content-Type: application/json" \
  -d '{"text":"他推开门，激动地说：\"你终于回来了！\"","roles":["他"]}' \
  --output novel.mp3
fetch 示例
const res = await fetch("/novelToTts", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ text: "他推开门，激动地说：你终于回来了！", roles: ["他"] }),
});
const blob = await res.blob();
new Audio(URL.createObjectURL(blob)).play();

响应：对应 format 的二进制音频

POST /novel/analyze

小说情感/角色分析：返回 JSON segments，供查看或二次调用 /novel/analyzeToTts。

请求参数（Body JSON）

参数类型必填默认说明
textstring是—小说文本（单次 ≤6000 字）
rolesstring[]否—角色名数组，辅助识别
curl 示例
curl -X POST http://localhost:8999/novel/analyze \
  -H "Content-Type: application/json" \
  -d '{"text":"他推开门，激动地说：你终于回来了！"}'
fetch 示例
const res = await fetch("/novel/analyze", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ text: "他推开门，激动地说：你终于回来了！", roles: ["他"] }),
});
const { segments } = await res.json();
console.log(segments); // [{ "role": "旁白", "text": "他推开门，", "emotion": "平静地叙述" }, ...]

响应：JSON，如 { "segments": [{ "role": "旁白", "text": "他推开门，", "emotion": "平静地叙述" }, { "role": "他", "text": "你终于回来了！", "emotion": "激动地说" }] }

POST /novel/analyzeToTts

将 /novel/analyze 返回的 segments 逐段合成并合并为最终音频。

请求参数（Body JSON）

参数类型必填默认说明
segmentsarray是—分段数组，每项含 role/text/emotion（最多 20 段）
voicestring否malele_3音色 id
speednumber否1.0语速
formatstring否mp3音频格式
bitratenumber否64仅 mp3，32~128 kbps
curl 示例
curl -X POST http://localhost:8999/novel/analyzeToTts \
  -H "Content-Type: application/json" \
  -d '{"segments":[{"role":"旁白","text":"他推开门，","emotion":"平静地叙述"},{"role":"他","text":"你终于回来了！","emotion":"激动地说"}],"voice":"malele_3"}' \
  --output novel.mp3
fetch 示例
const res = await fetch("/novel/analyzeToTts", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    segments: [
      { role: "旁白", text: "他推开门，", emotion: "平静地叙述" },
      { role: "他", text: "你终于回来了！", emotion: "激动地说" },
    ],
    voice: "malele_3",
  }),
});
const blob = await res.blob();
new Audio(URL.createObjectURL(blob)).play();

响应：对应 format 的二进制音频

📐 公共参数与约定

基础地址http://localhost:8999（端口可用 PORT 环境变量覆盖）
音频接口失败返回 4xx/500 文本错误信息（如 缺少 text 参数、TTS server error）
音色 voiceF5-TTS 服务端 voices.yaml 中的音色 id，如 malele_3，可经 /voices 获取
seed传数字可固定合成结果（相同输入 + 种子 = 相同结果）
formatwav / mp3 / ogg / flac，默认 mp3
bitrate仅 mp3 有效，范围 32~128 kbps，默认 64
文本长度限制小说接口单次输入上限 6000 字（NOVEL_MAX_TEXT_LENGTH），最多 20 段（NOVEL_MAX_SEGMENTS）
